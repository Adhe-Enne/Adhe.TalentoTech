# 📦 Adhe.React — Índice de proyectos

Este README actúa como un puente breve desde la carpeta raíz Adhe.React/. Contiene una descripción concisa de los proyectos disponibles en este nivel y enlaces directos a sus READMEs para más detalles.

## Proyectos

- **React-EjerciciosIncrementales**: Proyecto incremental del curso "React JS - Buenos Aires Aprende" (TypeScript + Vite). Serie de ejercicios que recorren componentes, hooks y patrones básicos. Ver: [React-EjerciciosIncrementales](React-EjerciciosIncrementales/README.md)
- **ProyectoPreEntrega — Adhe.E-commerce**: Mini tienda demo (React + TypeScript + Vite). Incluye providers para productos, carrito, favoritos y notificaciones; datos precargados en `public/productos.json`. Ver: [ProyectoPreEntrega](ProyectoPreEntrega/README.md)

## Estructura general

Breve visión de la organización en este nivel para orientarte rápidamente:

- `React-EjerciciosIncrementales/` — Aplicación React (TypeScript + Vite) organizada como ejercicios incrementales. Contiene `src/` (componentes, pages, hooks, `main.tsx`, `App.tsx`), `public/` y su `README.md`.
- `ProyectoPreEntrega/` — Demo de e‑commerce (Adhe.E-commerce). Incluye `public/productos.json`, `src/contexts/` (Products, Cart, Favorites, Notification), `src/components/` (home, product, cart), `package.json` y scripts de desarrollo.
- Archivos comunes: configuraciones de TypeScript y Vite (`tsconfig.json`, `vite.config.ts`), ESLint, y README específicos por proyecto.
